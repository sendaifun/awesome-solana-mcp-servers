# Contributing

This list is community-maintained. When adding or updating entries:

- Keep entries active and clearly scoped to Solana MCP tooling.
- Include a short, accurate description of what the server does.
- Prefer repos with clear install/setup docs and explicit runtime requirements.
- Verify links before merge (especially new GitHub URLs).
- Use the same alphabetical grouping style as existing sections.

When possible, add links to official docs and include caveats for API key requirements.
